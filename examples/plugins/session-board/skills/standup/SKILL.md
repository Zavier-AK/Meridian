# Stand-up

Call `check_workers`, then answer in four short sections, a line per item:

- **Landed** — merged changes, with the worker and one line on what changed.
- **Waiting for you** — changes for review and delegations to approve, oldest first.
- **Running** — who's working on what.
- **Blocked** — failures, with the reason in a few words.

Leave out an empty section. No preamble.
